## About

You are trapped inside an abandoned facility during a violent storm.
Something is hunting you in the dark — and it learns, listens, and reacts.

Your only defense is a fragile flashlight with limited battery. Light can repel
the creature, but darkness builds tension... and tension makes it faster.

Survive long enough to restore power, and escape.

<!-- CONTROLS -->
## Controls

| Key | Action |
|---|---|
| `WASD` | Movement |
| `Space` | Sprint / Dash |
| `F` | Flashlight |
| `E` | Interact |
| `Mouse` | Point flashlight |
| `Arrow Keys` | Puzzles |
| `X` | Fullscreen |
| `Q` | Pause |
